# 서울시 정비사업 기초 규모·사업성 분석 툴

(임시 어플리케이션 실험용임)

## 개요

서울시 정비사업(재개발·재건축) 초기 기획 단계에서 대지면적·용도지역 조건을 입력하면
**규모 산출 → 사업성 검토 → 법규 체크리스트**를 자동으로 생성하는 Streamlit 앱입니다.

## 주요 기능

- 용도지역별 법적상한용적률 기반 규모 자동 산출
- 자치구별 분양가 기반 사업성 개략 추정
- Claude AI(LLM) 기반 3단계 법규 체크리스트 자동 생성
- 주택건설기준 기반 부대시설 의무 항목 자동 체크

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## API 키 설정 (선택)

`.streamlit/secrets.toml` 파일 생성:

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
JUSO_API_KEY = "..."
VWORLD_API_KEY = "..."
```

API 키 없이도 목업 데이터로 동작합니다.

## 테스트 케이스

| 대지 | 대지면적 | 용도지역 | 예상 세대수(84㎡ 100%) |
|---|---|---|---|
| 서계동 가정 | 12,000㎡ | 제2종일반주거 | 약 250~270세대 |
| 청파동 가정 | 8,500㎡ | 제2종일반주거 | 약 180~200세대 |

## 주의사항

- 결과는 초기 기획 참고용이며 법적 효력 없음
- 분양가·공사비 단가는 개략값 (reference.py에서 업데이트 가능)
- LLM 체크리스트는 AI 생성값으로 전문가 검토 필수
- 서울특별시 도시계획 조례 2024년 기준 (개정 시 reference.py 업데이트)
